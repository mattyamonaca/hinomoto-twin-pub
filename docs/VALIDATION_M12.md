# 検証記録：M2・M12 の仮想人口評価と独立評価（Issue #21）

作成日：2026-09-07。対象は公開モデル v3.0-M12（γ=1.5、γ₂=1.0、β=0）と比較モデル M0／M0_notax／M1／M2。本文書は Issue #12 の残課題（[EXPERIMENT_M12.md](EXPERIMENT_M12.md)、[METHOD_M12.md](../METHOD_M12.md) の未検証範囲）を補完する。数値は `docs/experiments/validation_m12.json`、`synthetic_recovery_m12.json`、`validation_m12_areas.csv`（データルート `validation/` の複製）に対応する。**本検証で本番モデルは変更しない**。モデルの変更は評価結果に基づく別 PR で扱う。

## 1. 独立評価に使える統計の調査

| 候補 | 粒度・時点 | 判断 |
|---|---|---|
| 2022 就業構造基本調査 地域編（都市表：02300、表24 等） | 86都市（都道府県庁所在市・政令市・人口30万以上等）、2022年 | 開発で繰り返し使用しており独立ではない。都市行は都道府県集計にも含まれる。町村・行政区の表はない |

| 賃金構造基本統計調査 | 都道府県 × 産業 × 規模、月額賃金 | 市区町村の情報がない。未使用 |

課税状況調は課税対象所得（控除後・全納税義務者）であり、就業構造基本調査の「主な仕事からの年間収入」ではない。非課税者を含まず、年金・資産所得者を含む。したがって所得水準そのものではなく、**都道府県内での相対的な位置（対数偏差）の整合**を評価に使う。

入力の都道府県集計への依存：都道府県の所得構成比（`pref_target`）と地位別所得（`ess_cat`）は 86都市を含む県集計、町村の年齢 × 地位の初期値は県の 表3-1、多くの市区町村の学歴 × 労働力は県表、産業別所得形状は全国表である。都市表の out-of-fold 評価はこれらの入力と独立ではない。

## 2. 事前登録（結果を見る前に固定：2026-09-07 12:55 JST）

本節は `src/validate_m12.py` と `src/synthetic_population_m12.py` を実行する前に書き、実行後は数値の追記以外は変更していない。

### 2.1 実統計・同一分母の比較（Part A）
- 対象：86都市 × 年齢13区分のうち所得既知の復元人口 1,000 人以上の 1,118 セル（`validation/heldout_cities.csv` と同一）。全モデルで同じセル・同じ重み。
- 手順：都道府県コード mod 5 の5分割。学習分で M0 は β、M0_notax は固定 β=0、M1 は (γ, β)、M2 は (γ₂, β)、M12 は (γ, γ₂, β) を人口加重クロスエントロピー最小で選び、検証分の指標を集計（out-of-fold）。格子は既存実験と同じ。
- 指標：16階級 TV の人口加重平均、都市均等平均（都市ごとの平均をさらに都市間で平均）、セル均等平均、中央値、90%点、最大、M0 比の都市平均の最大悪化、所得閾値（≥300／≥500／≥700万円）の構成比の絶対誤差（加重平均）、都市規模（所得既知人口 20万人以上／8万人以上／未満）別の加重TV。
- 採用基準は既存の事前登録と同じ（相対改善 ≥ 1%、中央値が悪化しない、都市平均の最大悪化 ≤ 0.02）。本検証で本番係数は変更しない。

### 2.2 係数感度（Part B）
- 本番 M12（γ=1.5、γ₂=1.0、β=0）と近傍（γ 1.0／2.0、γ₂ 0.5／1.5、β 0.3、M1 の γ=2.0、M2 の γ₂=2.0・β=0.3、M0 の β=0.5、β=0）の都市 in-sample TV と、市区町村分布 P(所得｜地域, 性別, 年齢) の本番からの変化 TV（有給就業者加重平均、90%点、最大）を市・町村・区の別に報告する。町村・区は都市表がなく実測との比較はできないため、変化量の報告に限る。

### 2.3 独立評価（Part C）：令和5年度 市町村税課税状況等の調
- データ：総務省「令和5年度 市町村税課税状況等の調」第2表・第11表の市町村別内訳（1,741 市町村、2022年所得）。いずれのモデルの入力でもない（M0 の税務指標は 市区町村のすがた2024 の令和4年度＝2021年所得の平均値で、本番 M12 は β=0 で税務指標を使わない）。`catalog/tax_status/manifest.json` にハッシュを記録。
- 集計単位：政令市の区はモデル側を市に合算（課税状況調は市単位）。東京特別区は区ごと。
- 税務側指標（都道府県内の対数偏差、納税義務者数で加重した県平均からの差）：t1 = log(課税対象所得／所得割納税義務者数)、t2 = log(給与所得者の所得割額／給与所得者の所得割納税義務者数)、t3 = 均等割のみ納税義務者の割合（偏差）。
- モデル側指標（同じ県内偏差、有給就業者加重）：m1 = log(有給就業者の平均所得)（階級中点、最上位 1,750万円）、m3 = 100万円未満の有給就業者割合。
- 比較モデル：M0（β=0.5）、M0_notax（β=0；税務指標を使わない公平な基準）、M1（γ=2.0）、M2（γ₂=2.0、β=0.3）、M12（本番）。係数は既存実験の全都市学習値で固定し、本検証で選び直さない。
- 指標：m1–t1、m1–t2、m3–t3 の Pearson・Spearman 相関を全体・市・町村・政令市・特別区別に報告。方向整合性：Δ = m1(M12) − m1(M0_notax) と残差 (t1 − m1(M0_notax)) の相関（ブートストラップ 1,000 回の 95% 区間）と、Δ の符号が残差と一致する割合。
- 支持ルール：M12 が「独立指標に支持される」のは、市・町村・政令市・特別区の各群で m1–t1 の Pearson 相関が M0_notax より 0.01 を超えて低くならず、かつ全体の方向整合性相関の 95% 区間が 0 を含まない場合。満たさなければ「支持されない」と記録し、原因の特定は別作業とする。本ルールは本番モデルを変更しない。
- 限界（事前に認識）：課税対象所得は控除後・全納税義務者（年金・資産所得者を含む）の値で、有業者の就業収入ではない。非課税者は含まれない。したがって水準ではなく県内の相対順位の整合だけを見る。

### 2.4 仮想人口（M2/M12 を含む復元比較）
- 生成：6県 × 20市町村、学歴8区分 × 産業7区分（6群＋分類不能）× 地位5区分。所得は対数正規で、地位・学歴（θ_m）・産業（φ_m）・地域水準の効果を持つ。
- 観測表：既存（人口・就業・地位・県の所得調査 2% 抽出・税務指標・学歴人数・県の学歴×労働力）に加え、国勢調査 6-3 相当（地域 × 性別 × 年齢 × 産業、全数、分類不能を含む）と就業構造基本調査 表24 相当（全国 × 性別 × 産業 × 所得、年齢なし、2% 抽出）。
- シナリオ（各 5 seed）：基準（効果一定）、学歴・産業の関連が地域で変動、学歴×産業の交互作用（乗算近似の違反）、産業効果の年齢依存（表24 に年齢がない仮定の違反）、産業効果の地域差（全国形状移植の違反）、情報のある不詳（学歴不詳・産業不詳が低所得に偏る）、小規模地域（人口 300〜2万、空セル多数）、産業の直接効果なし、学歴の直接効果なし、すべての違反＋税務指標ノイズ 0.3。
- 係数選択：県内上位3市の都市表で人口加重クロスエントロピー最小（格子 γ ∈ {0,1,2,3,4,6}、γ₂ ∈ {0,1,2,3,4}、β ∈ {0,0.5,1,2,3}）。評価は全市町村 × 性別 × 年齢の隠した真値に対する有給就業者加重 TV（全モデル同一分母）、地域均等平均、中央値、90%点、最大、閾値誤差、小規模／大規模地域別、学歴別 TV、M0 比の地域最大悪化・改善地域割合。
- 判断：seed 平均の M12 − M0 が負で seed 範囲の上限が +0.001 以下なら「その条件で悪化しない」、それ以外は条件と方向を記録する。日本の実態に対する精度保証ではない。

- 事前の判断基準（seed 平均が負で seed 範囲の上限 ≤ +0.001）で「悪化しない」のは、基準・学歴×産業の交互作用・産業効果の年齢依存・産業効果の地域差・情報のある不詳・学歴の直接効果なし・全違反＋弱い税務指標の 7 条件。地域で関連が変動する条件は上限 +0.0005 で基準内、小規模地域（+0.0012）と産業の直接効果なし（+0.0001）は差がゼロ付近で、改善も悪化もしない。
- **乗算近似（学歴 × 産業の交互作用）**：交互作用 sd 0.25 の世界でも M12 は M1・M2 より良く（0.0799 対 0.0828／0.0807）、M12 − M0 は −0.0037。乗算近似は交互作用がある生成過程でも復元を悪化させなかった。ただし交互作用は世界ごとに固定した確率的パターンで、系統的な符号（高学歴 × 高所得産業で上乗せ）は試していない。
- **全国形状の移植・年齢なし**：産業効果が年齢で変わる世界（表24 に年齢がない仮定の違反）と地域で変わる世界（全国形状の移植の違反）でも M12 は M0 より −0.0027／−0.0024 改善し、M2 単独とほぼ同じ。違反による損失は M2 の利得を打ち消すほどではなかった。
- **産業の直接効果がない世界**では M2・M12 は M0 と同じ水準（差 −0.0001、seed 範囲 −0.0004〜+0.0001）で、γ₂ は 0〜1 が選ばれることが多い。産業構成が所得と無関係な世界で誤って傾ける害は検出されなかった。
- **小規模地域**（人口 300〜2万、県の所得調査は 2% 抽出）では全モデルとも TV 0.27 で、県目標自体の標本誤差が支配する。学歴・産業構成は役に立たず、害もない。日本の町村の精度がこの水準だという主張ではなく、県の標本サイズが小さいと構成情報では補えないことを示す。
- **学歴の直接効果がない世界**でも M1 は改善し γ は格子上限 6 が選ばれる（学歴と地位・都市度を介した間接的関連が残るため）。M12 では γ₂ が 1〜2 で選ばれ、学歴の γ は 0〜6 とばらつく。学歴と産業の情報は代替関係にあり、係数の値はどちらの構成が所得差を担っているかを識別しない。
- 税務指標が弱く全違反を含む世界では M12 の改善が最大（−0.0215）で、M1 比でも −0.0113。M0 比の地域最大悪化は +0.086 と大きく、改善地域は 68%。
- 学歴別 TV（学歴配分後）は全条件で M0 → M12 が同等か改善（0.0569→0.0563 等）。地域均等平均も同じ順位。M12 の M0 比の地域最大悪化は通常 +0.02〜0.04 で、改善地域の割合は 56〜62%。悪化する地域が 4 割ある点は、実データで都市平均の最大悪化 +0.0096 を見ていることと整合する。

選ばれた係数（seed ごと）は `docs/experiments/synthetic_recovery_m12.json` の `selected` に記録している。多くのシナリオで γ が格子上限（6）に達する seed があり、都市表による係数選択は仮想世界でも不安定である。実データの γ=1.5 は格子内部で選ばれているが、3.2 の平坦さと合わせ、係数の値自体に強い根拠があるとは言えない。

## 5. 検証できた範囲・できない範囲（更新）

- できたこと：(1) 86都市の out-of-fold 比較を M0/M0_notax/M1/M2/M12 で同一分母・複数指標（都市均等・中央値・上位誤差・最大悪化・閾値誤差・規模別）で報告。(2) 全 1,740 市区町村について、どのモデルの入力でもない 2022 年所得の税務統計との県内相対水準の整合を確認し、M12 は事前登録の支持ルールを満たす。(3) 乗算近似・全国形状移植・情報のある不詳・小規模地域・産業無関係の各違反条件での復元を仮想人口で確認。(4) 係数感度：都市表の当てはまりは平坦で、市区町村分布は係数 ±0.5 で TV 0.007〜0.010 動く。
- できていないこと：町村・行政区・性別別・学歴別の所得**分布**の実測比較（分布の公表表がない。税務統計は総額のみ）。市町村別の課税標準額段階別分布は公表されていない。真に未使用の都市集合による分布レベルの独立テストは現状の公表統計では作れない。2017 年調査は同じ都市集合であり時点も合わないため未使用。
- 判断材料として残ること：独立指標は M12 の学歴側の効果を支持するが、産業側の傾きは町村で独立指標と整合しない（M12 − M1 の方向整合性が町村で負）。都市表では M12 と M1 の差は 0.14% で判別できない。**M1（γ=2.0、β=0）への切り替え、または町村で γ₂ を抑える設定は、この結果に基づく別 PR の検討対象**とし、本 PR では変更しない。
- 税務統計との比較は概念差（控除後・全納税義務者・非課税者除外）があり、相関の水準はモデルの精度を意味しない。

## 6. 再現

```sh
export HINOMOTO_DATA_ROOT=../hinomoto-twin-data
make build                # 本番 M12 の入力（正規化済み統計）
make fetch-industry       # M2 の産業表（初回のみ）
make fetch-tax-status     # 令和5年度 課税状況調 第2表・第11表（総務省サイトから取得、SHA-256 検証）→ sources/tax_status/
make validate-m12         # Part A/B/C → validation/validation_m12.json, validation_m12_areas.csv, validation_m12_cells.csv
make synthetic-m12        # 仮想人口 → validation/synthetic_recovery_m12.json, .csv
```

入力版：`catalog/manifest.json`・`catalog/industry/manifest.json`・`catalog/education/manifest.json`・`catalog/tax_status/manifest.json` の SHA-256 を `validation_m12.json` の `inputs` に記録。係数格子・分割・seed・選択規則は各 JSON の `protocol`／`grid`／`seeds`／`selection`。仮想人口の seed は 1〜5、係数選択はスクリプト内の格子。テストは `tests/test_validation_m12.py`（生成器の契約、観測表の形、同一分母指標、4モデルの実行）。
