# 段階B：世帯構成の生成（Issue #16、選択地域での試験）

更新日：2026-09-08。港区（13103）、那覇市（47201）、遠軽町（01555）の3地域で、2020年国勢調査の公表表だけから世帯構成（世帯人数、家族類型、世帯内役割、構成員の性別・年齢）を生成し、推定に使っていない表で復元を評価しました。個人の15歳以上属性（年収など）とは独立に生成しており、結合方法は第6節に記します。

## 1. 参考研究との対応

| 研究 | 参考にした点 | 本プロジェクトでの対応 | 対応しない点 |
|---|---|---|---|
| 原田・村田・枡井（2018）家族類型と世帯内役割を考慮したSA法による世帯合成 | 家族類型と世帯内役割（世帯主・配偶者・子など）を明示して世帯を作り、年齢の整合をとる。使用統計を増やして誤差を減らす | 家族類型7区分 × 続き柄13区分 × 性別 × 年齢18区分の構成員表を市区町村の公表表に合わせ、世帯主の年齢を条件に配偶者・子・親などの年齢を割り当てる | SA による個票の属性交換は行わず、期待人数の表を反復比例調整で作る（確定的）。世帯所得や構成員間の所得相関は扱わない |

## 3. 生成方法と制約

1. 都道府県の続き柄別の構成を初期値とし、世帯主・構成員の集計表を反復比例調整で作る。
2. 家族類型別世帯数・人員、人数別世帯数を合わせ、世帯主の性別・年齢・家族類型・人数ごとに構成員の期待人数を置く。年齢差の事前分布は従来の独自仮定を使用する。
3. 以下の禁止する組み合わせを除いて、残っている候補に重みを比例配分する。世帯主セルごとの世帯数・構成員数を維持する。候補がないときは一様分布で埋めず、生成を停止する。
4. 続き柄の期待人数の累積和を、世帯ごとに一つの一様乱数で丸める。各続き柄は期待人数の切り捨て／切り上げ人数になり、平均人数を保つ。配偶者の期待人数が1以下なら2人になることはない。人数1〜9は指定人数、10人以上は平均人数の前後の整数人数になる。この連動した丸め方は実装上の選択であり、実際の世帯内の相関を観測したものではない。
5. 決まった続き柄ごとに性別・年齢を抽出する。解析的な「少なくとも1人いる確率」も同じ丸め方の全乱数区間を積分して計算し、実際の抽出と一致させる。

適用する制約（`src/household_constraints.py`）：

- 世帯主は1人、世帯主の配偶者は最大1人。
- 夫婦のみは世帯主と配偶者の2人。夫婦と子供は現行モデルで世帯主と配偶者を夫婦に固定しているため、残りは子だけとする。**子を世帯主とする夫婦と子供の世帯まで再現するものではない。**
- ひとり親と子供・単独に世帯主の配偶者を置かない。単独は世帯主1人。
- 15歳未満の配偶者、15歳未満の世帯主に対する配偶者は生成しない。15〜19歳は一つの階級なので除外しない。
- 15歳以上の世帯主に、15歳未満の「世帯主の父母」を割り当てない。一般的な親子の年齢差や、義理の親と世帯主の年齢の大小を一律には制約しない。

続き柄は[世帯主との関係](https://www.e-stat.go.jp/surveyitems/items/001010002)を表す。[家族類型の定義](https://www.stat.go.jp/data/kokusei/2020/kekka/pdf/ug_03.pdf)と、現行モデルで世帯主をどう置いているかを区別する。年齢は5歳階級で扱う生成上のルールで、個々の婚姻の法的判断ではない。2020年の婚姻開始年齢は男女とも18歳に統一される前であるため、現在の年齢をそのまま適用しない。[法務省の説明](https://www.moj.go.jp/MINJI/minji07_00218.html)

禁止セルへの質量を除くため、**続き柄・性別・年齢の周辺は補正前から変わり得る**。再配分した期待人数と性別・年齢の変化量を `structural_constraints` に記録し、最終表と個票を検査する。制約と衝突する周辺を無理に同時達成したとは表示しない。

## 4. 制約適用後の検証

期待人数表の結果。TVは分布間のずれ（0が一致）で、推定人数の誤差率ではない。性別×年齢の比較先は一般世帯人数に比例縮小した人口。都市13-2は比較可能な都市表との比較。

性別・年齢の周辺とのずれは制約適用で増えるため、これは全面的な精度向上の主張ではない。定義・生成ルールへの整合を優先した変更である。所得分布の係数や学歴補正は変更していない。

## 5. 限界

- 今回の制約はすべての親族関係を網羅しない。年齢差の大小だけで夫婦・親族を排除しない。再婚・養子・きょうだいの年齢間隔などの詳細を再現していない。
- 家族類型×人数は世帯主年齢別には調整していない。夫婦と子供では世帯主と配偶者を夫婦とする既存の仮定が残る。
- 不詳の補完、都道府県からの続き柄構成の移植、年齢差の事前分布は独自仮定であり、今回の制約で妥当性が保証されるものではない。
- 集計前のXと制約後のTは別物。Xの周辺一致をTや個票の一致として扱わない。
- サイトは3地域の試験公開である。

## 6. 個人属性との結合

構成員の市区町村・性別・年齢帯から個人モデルの学歴・就業・産業・年収を条件付きで抽出する。15歳未満にはこれらを付与しない。世帯内の所得・学歴の相関は未観測なので独立に引く。就業収入の合計を「世帯年収」と呼ばない。世帯制約による構成員の年齢構成の変化はあり得るが、個人モデルそのものは変えていない。

## 7. 整数個票と再現

### 7.1 API

```sh
make fetch-household
make build-household
python src/household_sample.py --municipality 13103 --households 10 --seed 1
python src/household_sample.py --municipality 13103 --population --seed 1
# 3地域とも生成してから画面用の集計を作る
make export-household-web
make verify-household-constraints # 全個票と乱数を変えた追加9万世帯を検査
```

`--link` は抽出した世帯に、`--link-population` は整数個票全体に個人属性を結びつける。出力は外部データワークスペースの `data/household_b/`、検証結果は `validation/`。期待表に `constraints_version` を記録し、画面用の書き出しでも実際の個票を検査する。古いデータに制約が適用されたとは表示しない。

### 7.2 抽出後の確認

seed 1の全世帯と、seed 42・1234・20260908で各地域10,000世帯ずつ（追加90,000世帯）を確認。今回の制約違反はすべて0件。数学的に維持するのは続き柄ごとの期待人数で、有限回の抽出人数には標本変動がある。家族類型×人数ごとの世帯数は管理丸めで期待値から±1以内。

| 地域 | 個票の世帯数 | 構成員数 | 今回の制約違反 |
|---|---:|---:|---:|
| 港区 | 146,083 | 258,881 | 0 |
| 那覇市 | 144,012 | 309,731 | 0 |
| 遠軽町 | 8,739 | 18,035 | 0 |

抽出方法の根拠は人数の保存と重複防止であり、現実の世帯内相関に最も近いことを実証したわけではない。詳細は `docs/experiments/household_structural_review.json` と各地域の検証結果を参照。年齢の属性交換や独立抽出は、この制約を満たす代替手法として採用していない。

遠軽町では6歳未満のいる世帯が公表値より12.3%多い。制約は不適切な続き柄を防ぐもので、公表分布との誤差を必ず改善するものではない。性別×年齢の構成が変わる影響と、少数世帯での抽出変動が残る。年齢差の事前分布や不詳補完の改善は今回の対象外。

### 7.3 画面表示

世帯構成パネルとM5の導出に制約を掲載。詳しいルールは「世帯を作るときの制約と限界」を開くと読める。15歳未満の「世帯主の子である割合」は続き柄が子の人だけを数え、孫などを含めない。孫が自分の親と同居しているかどうかは、この指標だけでは判定しない。
