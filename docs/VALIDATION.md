# 検証結果と限界

[使い方](../README.md) ／ [現在の推定方法](../METHOD.md) ／ [データと再現手順](../DATA.md)

現在の公開分布について、確認済みの範囲をまとめます。統計の合計に一致することと、未観測の属性の組み合わせが正しいことは別です。過去の方式だけで行った評価を現在の精度として表示しません。

| 検証 | 現在分かっていること | 限界・詳細 |
|---|---|---|
| 入力統計との整合 | 地域の人口・学歴人数、都道府県の性別・年齢別の所得既知有業者の構成比など、推定で指定した制約を確認 | 原表間の不詳・分母の接続後の制約。すべての原表の総数行に一致するわけではない。[推定方法](../METHOD.md) |
| 都市の年収分布との比較 | 86都市 × 年齢13区分、1,118セルの開発データで、交差検証の加重総変動距離（TV）が比較用の基礎モデル0.09327747から学歴・産業補正あり0.08987450へ改善 | TVは二つの階級構成の差で、小さいほど一致する。全都市で選んだ固定係数の公開値の指標とは異なる。都市表は開発で繰り返し使用し、入力の県集計にも含まれるため完全な独立テストではない。[比較記録](VALIDATION_M12.md) |
| 推定に使わない税務統計との比較 | 令和5年度の市町村税統計で、2022年所得の県内相対水準の整合を評価。人口のある1,740市区町村が対象 | 課税所得は就業年収と定義・対象者が異なる。町村では産業補正が独立指標と逆方向に動く傾向があり、年収分布の精度保証にはならない。[評価記録](VALIDATION_M12.md) |
| 正解が分かる仮想人口 | 学歴・産業の交互作用、年齢依存、地域差、不詳、小規模地域などの条件で現在の方式を比較済み | 仮想的な生成条件での復元能力。日本の実測精度ではない。[実験条件と結果](VALIDATION_M12.md) |
| 仮定・係数を変えた比較 | 学歴・産業の補正係数を変えて都市への当てはまりと地域別分布の変化を確認。近傍の係数で都市の当てはまりはほぼ平坦 | 係数は強く特定されていない。過去の学歴感度分析の数値は現在の方式に転用しない。[感度の記録](VALIDATION_M12.md) |
| 就業・世帯・勤務地 | 機能ごとに整合・復元を確認。勤務地は推定に使わない第9・10表と比較。世帯は3地域で評価 | 対象・採用条件は機能ごとに異なる。[就業](EMPLOYMENT_A.md)・[世帯](HOUSEHOLD_B.md)・[勤務地](WORKPLACE_C.md) |

## 未確認の範囲

- 町村・行政区の所得分布そのもの、性別別・学歴別、非就業者を含む住民全体の細かい所得構成には、公表された正解表との十分な比較がありません。
- 全国の学歴別・産業別所得形状を各地域に当てはめる仮定が残ります。産業別所得形状には年齢区分がありません。
- 学歴不詳が多い地域では、分かっている人の構成を地域全体の構成とはみなせません。
- 世帯内の所得相関、細かい親族間の年齢関係、勤務地と年齢・性別・学歴の未観測の関連は実証されていません。
- 2020年人口と2022年所得を組み合わせており、現在の人口・賃金を推計したものではありません。

## サイトで確認する

数値の説明から参照データのMを開くと計算工程、そこにある「独自仮定」から検証状況へ進めます。「直接検証済み」も記載された範囲に限られ、「間接評価のみ」は仮定自体の実測確認ではありません。生成スクリプトが公開されていることと、その仮定が検証済みであることも区別します。

[詳細な実験記録](VALIDATION_M12.md)は、比較モデルの識別子・評価前に定めた条件・実測値を保つため独立した資料として残しています。別の公開バージョンの説明書ではありません。
