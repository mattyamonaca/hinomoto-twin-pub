1 / 推定対象

何を推定しているか

市区町村 m、年齢階級 a、年収階級 y に対する推定人数を X(m,a,y)、15歳以上人口を N(m)、該当年齢の人口を N(m,a) とします。

主出力 P(a, y | m) = X(m,a,y) / N(m) 地域内で全 a,y を足すと 1 年齢条件付き P(y | m, a) = X(m,a,y) / N(m,a) 年齢構成 P(a | m) = N(m,a) / N(m)

周辺分布だけからは同時分布は識別できません。このモデルは、地域別の人口・就業構成（国勢調査）、都道府県内の年齢・性別・就業形態と所得の関連（就業構造基本調査）、地域の課税所得水準（市区町村のすがた）を使って未観測部分に仮定を置き、公表集計値に合致する分布を構成します。潜在属性として性別 s と就業形態 k（正規・非正規・役員・自営・無給家族従業の5群）を内部で持ち、最後に集約します。

記号意味区分数由来
m非重複の地域（区・市・町村）。出力時に政令市20市を区の和で追加1,896 → 1,916国勢調査 2020年境界
pm が属する都道府県47地域コード上2桁
a年齢階級。15～19歳から70～74歳まで5歳刻み、75歳以上13両統計で共通
s性別（内部のみ）2国勢調査・就業構造基本調査
k就業形態：正規／非正規／役員／自営（内職含む）／無給家族従業（内部のみ）5従業上の地位を集約
y主な仕事からの年収階級。50万円未満から1,500万円以上まで16就業構造基本調査の所得階級

年収は「主な仕事から通常得る年間収入」で、給与は賞与込み・税引前、自営は必要経費控除後です。副業・年金・資産収入は含みません。「50万円未満」には非就業者と無給家族従業者のモデル上の0円を含みます。

②build.py

人口への接続

入力W(m,s,a,k)、S1 N、S2 Nraw
→
処理地域・性別・年齢ごとに W を N / Nraw 倍する。Nraw = 0 で N > 0 のセルは、都道府県の就業率と初期表の構成を使って埋める。
→
出力接続後の W、有給就業者数 E(m,s,a) = Σk≠家族 W
W(m,s,a,k) ← W(m,s,a,k) × N(m,s,a) / Nraw(m,s,a) E(m,s,a) = W(正規) + W(非正規) + W(役員) + W(自営) 家族従業は0円成分へ
仮定・注意
  • 年齢を補完された人も、その地域・性別・年齢の既知の人と同じ就業率・就業形態分布に従うと仮定する。
  • 接続後の人数は公表就業者数と一致しない。最終モデルは人口表と就業表の全公表人数に同時に一致することを主張しない。
  • 推定有給就業者は全国で 65,597,912 人（実数値）。

③build.py

所得分布 r(y｜p,s,a,k) の作成

入力S5 都道府県 × 性別 × 年齢 × 地位 × 所得の人数 C、全国の同表
→
処理地位コードから4群を組み立て、所得不詳を除いた16階級を全国分布に向けて平滑化し、正規化する。
→
出力r(y|p,s,a,k)　47 × 2 × 13 × 4 × 16
正規 = 地位 22 非正規 = 地位 23 自営 = 地位 1 役員 = max(地位 2 − 22 − 23, 0) 残差近似。負の431セル（すべて −100人）は 0 に切上げ r(y|p,s,a,k) = [ C(p,s,a,k,y) + 1000 · rN(y|s,a,k) ] / [ Σy C(p,s,a,k,y) + 1000 ]

1000 は公表の復元人口と同じ単位で置いた正則化の強さで、標本数ではありません。平滑化の重み 1000 / (既知合計 + 1000) は都道府県 × 性別 × 年齢のセルごとに異なり、小さな群ほど全国分布に近づきます。

⑥refine_tax.py

税務補助情報による地域差の付与

入力X、S6 課税対象所得・納税義務者数、S5 86都市の所得表（β選択用）
→
処理地域の所得水準スコア h(m) と所得階級スコア g(y) の積で X を傾け、⑤と同じ行・列合計に IPF で戻す。傾きの強さ β は都市の公表所得表への当てはまりで選ぶ。
→
出力X′(m,s,a,y)　→ final_arrays.npz
t(m) = 課税対象所得(m) / 納税義務者数(m) t(p) = 都道府県の同値 h(m) = clip( log[ t(m) / t(p) ], −0.5, +0.5 ) g(y) = log( 階級代表額(y) / 300万円 ) 代表額 25, 75, …, 1375, 1750 万円 X′ ∝ X · exp( β · h(m) · g(y) ) → IPF で行合計 E(m,s,a)、列合計 Σm X(m,s,a,y) に戻す

β の探索

86都市 × 年齢 1,118セル、復元人口加重の全変動距離 TV（全都市学習）

補助変数 log[t(m)/t(p)] の分布

葉地域 1,896。範囲 −0.53 〜 +1.30、±0.5 でクリップした地域は 9

βの候補
0 〜 4、0.1 刻み（41点）
損失
86都市 × 13年齢の公表所得構成に対する復元人口加重クロスエントロピー
交差検証
都道府県コード mod 5 の5分割。学習外の β は 0.6, 0.6, 0.5, 0.5, 0.5
採用
β = 0.5（全都市学習と同じ）。交差検証のTVが税補助なしを下回ったため採用。下回らなければ β = 0 に戻す設計
補助値の代替
175行政区は親市の値、税務値が欠ける場合は都道府県値
仮定・注意
  • 課税所得には就業外所得が混ざり、分母は課税対象者のみ。給与平均への置換や、モデル平均を税務平均に一致させる処理はしていない。
  • 代表額は傾けるためのスコアであり、階級内の年収や平均を推定した値ではない。
  • 都市の所得表は都道府県表にも含まれる。交差検証で分離したのは β の学習だけで、独立標本による精度推定ではない。

⑦build.pyrefine_tax.py

非就業者の追加と正規化

入力X または X′、N、E
→
処理Z = N − E（非就業者と無給家族従業者）を「モデル上の0円」成分として先頭に付け、性別を足し合わせ、地域人口で割る。
→
出力C(m,a,y)、P(a,y|m)　内部は17成分（0円 + 16階級）
C(m,a,y) = Σs [ Z(m,s,a) , X′(m,s,a,1..16) ] P(a,y|m) = C(m,a,y) / N(m) 構造的0成分の全国比率 = 40.96%
仮定・注意
  • 国勢調査は調査週の就業、就業構造基本調査は普段の就業を捉える。季節就業や2020〜2022年の変化は接続していない。
  • 0円と少額収入、事業赤字は独立に推定できない。出力では0円成分を「50万円未満」に統合し、厳密な0円確率は提供しない。

9 / 限界と注意

この推定が言えないこと

  1. 同じ年齢・性別・就業形態でも、学歴・職業・産業・勤務時間・勤務先・移住選択による地域差が残る。公開表で分からない要因は捉えていない。
  2. 町村・各行政区の実測所得クロス表は検証していない。大都市で選んだ補助係数 β を小地域にも移植している。
  3. 所得不詳の扱い、役員の残差近似、平滑化 1000、税務代理変数、人口補完の接続は推定上の選択であり、別の選択で結果は変わる。
  4. 2020年（人口・就業・境界）、2021年（税務）、2022年（所得）の混合で、2026年の現況や地域再編を表していない。
  5. 住民集団の分布であり、実在する個人の所得を特定するものではない。人口が正の1,915地域で分布が定義される。
  6. 税補助なしの列は構造的な感度比較の一つで、信頼区間ではない。復元人口を標本数とみなした区間推定は作成していない。

推計値を公表する際は「国勢調査・就業構造基本調査・市区町村のすがたを加工したモデル推定」と明記し、基準年と所得定義を併記してください。詳細は METHOD.md、出典は SOURCES.md と sources/manifest.json を参照。
